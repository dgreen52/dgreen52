🌐 **[dillongreen.dev](https://dillongreen.dev)** · ✉️ dillon@dillongreen.dev

### What I build

- **Production tools for aviation operations.** An internal parts, procurement and maintenance platform for an airline simulator department: ~72k lines, 340+ automated checks, used daily. The code is my employer's, so it's private; here's the [case study](https://dillongreen.dev/par.html).
- **[Linework](https://github.com/dgreen52/linework)**: a lightweight CAD viewer and editor in the browser. Opens DXF, DWG and MicroStation DGN; measure, mark up, edit, copy/paste and save, fully offline. ([try it](https://linework.dillongreen.dev))
- **Avionics utilities.** [pocket429](https://pocket429.dillongreen.dev) decodes and builds ARINC 429 data words: BNR, BCD, ISO-5 text, parity, and on-device OCR of analyzer screens. [dgn-v7-toolchain](https://github.com/dgreen52/dgn-v7-toolchain) edits and batch-converts legacy MicroStation drawings.
- **Apps, games and extensions.** A recipe app with a native Swift OCR plugin, a real-time multiplayer browser game on Cloudflare Durable Objects, and a handful of privacy-first browser extensions ([crisp-pdf](https://github.com/dgreen52/crisp-pdf), [RetrOS](https://github.com/dgreen52/RetrOS)).
